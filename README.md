# ML Experiment Tracking with MLflow

## Project Overview

This project demonstrates ML experiment tracking using **MLflow** for a California Housing price prediction problem.

The goal is to train the same XGBoost regression model with three different hyperparameter configurations, track the experiments, compare their performance, and select the best-performing model.

---

## Project Structure

```text
mlflow-task/
│
├── train.py
├── requirements.txt
├── README.md
├── .gitignore
├── mlruns.db
└── artifacts/
```

> `mlruns.db` and `artifacts/` are generated by MLflow and should not be committed to Git.

---

## Dataset

The project uses the **California Housing dataset** provided by Scikit-learn.

The dataset is split into:

- **80% Training data**
- **20% Validation data**
- **Random seed:** `42`

---

## Experiments

Three XGBoost regression experiments were performed using different hyperparameter configurations.

| Run | max_depth | learning_rate |
|---|---:|---:|
| Run 1 | 3 | 0.10 |
| Run 2 | 5 | 0.05 |
| Run 3 | 7 | 0.01 |

For each experiment, MLflow tracks:

- `max_depth`
- `learning_rate`
- RMSE
- MAE
- R²
- Trained XGBoost model artifact

---

## Results

| Run | max_depth | learning_rate | RMSE | MAE | R² |
|---|---:|---:|---:|---:|---:|
| Run 1 | 3 | 0.10 | 0.5433 | 0.3710 | 0.7747 |
| **Run 2** | **5** | **0.05** | **0.5215** | **0.3534** | **0.7924** |
| Run 3 | 7 | 0.01 | 0.7006 | 0.5329 | 0.6254 |

---

## Best Model

**Run 2** was selected as the best-performing model.

### Configuration

```text
max_depth = 5
learning_rate = 0.05
```

### Performance

```text
RMSE = 0.5215
MAE  = 0.3534
R²   = 0.7924
```

Run 2 was selected because it achieved the **lowest RMSE** among the three experiments.

## MLflow

MLflow was used to:

1. Track experiment parameters.
2. Log model performance metrics.

4. Compare the three experiments through the MLflow UI.
5. Select the best-performing configuration.

## How to Run

### 1. Create the Virtual Environment

On Windows PowerShell:

```powershell
python -m venv mlops-env
```

Activate the environment:

```powershell
.\mlops-env\Scripts\Activate.ps1
```

---

### 2. Install Dependencies

Install the required Python packages:

```powershell
pip install -r requirements.txt
```

---

### 3. Start the MLflow Server

Open a separate terminal, activate the virtual environment, and run:

```powershell
mlflow server --backend-store-uri sqlite:///mlruns.db --default-artifact-root ./artifacts --host 127.0.0.1 --port 5000
```

The MLflow UI will be available at:

```text
http://127.0.0.1:5000
```

---

### 4. Run the Training Script

In another terminal, activate the virtual environment and run:

```powershell
python train.py
```

The script will:

- Load the California Housing dataset.
- Split the dataset into training and validation sets.
- Train three XGBoost models.
- Log hyperparameters to MLflow.
- Calculate RMSE, MAE, and R².
- Log metrics to MLflow.
- Save each trained model as an MLflow artifact.

---

### 5. Compare the Experiments

Open the MLflow UI:

```text
http://127.0.0.1:5000
```

Navigate to:

```text
California_Housing_Optimization
```

The three runs can then be compared using their parameters and validation metrics.

---

## Conclusion

This project demonstrates the complete ML experiment tracking workflow:

**Train → Track → Compare → Select**

Based on the validation results, **Run 2** achieved the best performance with:

```text
max_depth = 5
learning_rate = 0.05
RMSE = 0.5215
MAE = 0.3534
R² = 0.7924
```

Therefore, **Run 2 was selected as the best model** based on the lowest RMSE.
